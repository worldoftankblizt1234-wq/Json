# 🌍 Age of History (AoH)

## Giới thiệu
Age of History là game chiến lược realtime multiplayer, nơi bạn điều khiển một quốc gia, xây dựng, phát triển và chinh phục.

## Tính năng
- 🗺️ Bản đồ 180x100 ô lục giác
- 👥 Chơi đa người tối đa 10 người
- 🤖 AI thông minh
- 🏗️ Hệ thống công trình đa dạng
- ⚔️ Chiến tranh realtime
- 📊 Chính sách quốc gia (Thuế, Hàng hoá, An sinh, Khoa học)
- 💰 Lạm phát
- 📱 Hỗ trợ PWA

## Cách chơi
1. Đăng nhập bằng tên
2. Vào phòng chờ, chọn quốc gia
3. Xây dựng và phát triển
4. Tấn công và chinh phục

## Công nghệ sử dụng
- HTML5 + CSS3 + JavaScript
- Canvas
- Firebase Realtime Database
- PWA
